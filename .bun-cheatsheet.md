# Bun Cheat Sheet - Betting-Brain v3

Quick reference for Bun commands in this project.

## 📦 Package Management (80× faster than npm)

### Drop-in replacements
```bash
npm install           →  bun install
npm i @types/bun      →  bun add @types/bun
npm i -D typescript   →  bun add -d typescript
npm rm lodash         →  bun remove lodash
npm ci                →  bun install --frozen-lockfile
```

### Common tasks
```bash
# Fresh install
bun install

# Production only (no devDependencies)
bun install --production

# CI mode (don't modify lockfile)
bun install --frozen-lockfile

# See what changed before installing
bun install --dry-run

# Silent mode (no logs)
bun install --silent

# Lockfile only (no actual install)
bun install --lockfile-only

# Global packages
bun add -g wrangler
bun add -g typescript
```

### Git dependencies
```bash
# GitHub shorthand
bun add github:colinhacks/zod

# SSH
bun add git+ssh://github.com/lodash/lodash.git#4.17.21

# HTTPS
bun add git+https://github.com/iamkun/dayjs.git

# Tarball
bun add https://registry.npmjs.org/zod/-/zod-3.22.4.tgz
```

## 🔧 Project-Specific Commands

### Development
```bash
# Start worker locally
bun run dev                    # wrangler dev --local

# Start dashboard server
bun dashboards/server.ts       # http://localhost:8081

# Type check
bun run type-check             # tsc --noEmit
```

### Testing
```bash
# Run all tests
bun test

# Watch mode
bun test --watch

# Coverage
bun test --coverage

# Specific file
bun test tests/unit/clv.test.ts

# Integration tests
bun run test:integration
```

### Scripts
```bash
# Sync agent tree from Fantasy402
bun scripts/sync-agent-tree.js

# Build agent tree from cache
bun scripts/build-agent-tree-kv.js

# Test MCP handlers directly
bun scripts/test-handlers-direct.ts
```

### Deployment
```bash
# Deploy to Cloudflare
bun run deploy                 # wrangler deploy

# Apply database migrations
wrangler d1 migrations apply betting-analytics --local
wrangler d1 migrations apply betting-analytics --remote
```

## ⚙️ Configuration (bunfig.toml)

Our project uses these defaults:

```toml
[install]
registry = "https://registry.npmjs.org/"
optional = true          # Install optionalDependencies
dev = true              # Install devDependencies
peer = true             # Install peerDependencies
production = false      # Not in production mode
frozenLockfile = false  # Allow lockfile updates
linker = "hoisted"     # Fast, npm-like structure

[test]
timeout = 10000         # 10s default timeout
coverage = false        # Off by default
coverageThreshold = 0.8 # 80% required
```

## 🛠️ Advanced Features

### Isolated installs (pnpm-style)
```bash
# One-off isolated install
bun install --linker isolated

# Make it permanent
# Edit bunfig.toml: linker = "isolated"
```

### Package inspection
```bash
# List installed packages
bun pm ls

# Find specific package
bun pm ls | grep zod

# Binary locations
bun pm bin              # project bins
bun pm bin -g           # global bins

# Cache location
bun pm cache

# Clear cache
bun pm cache rm
```

### Workspaces (if needed)
```bash
# Install in specific workspace
bun add zod --workspace @acme/api

# Install in all workspaces
bun add lodash --workspaces

# Filter by pattern
bun install --filter 'ui-*' --filter '!ui-old'
```

## 🚀 Performance Tips

### Speed comparison
- **Linux**: 20-100× faster than npm
- **macOS**: 4-80× faster than npm
- **Windows**: 2-10× faster than npm

### Optimization checklist
- ✅ Use `bun.lock` (faster than `package-lock.json`)
- ✅ Keep dependencies minimal
- ✅ Use `--frozen-lockfile` in CI
- ✅ Leverage Bun's built-in transpiler (no build step for TS)
- ✅ Use `Bun.file()` instead of `fs.readFile()`
- ✅ Use `Bun.$` instead of `child_process.exec()`

## 📋 Common Issues

### Port already in use (dashboard server)
```bash
# Edit dashboards/server.ts
const PORT = 8082; # Change from 8081
```

### Lockfile conflicts
```bash
# Regenerate lockfile
rm bun.lock
bun install
```

### Peer dependency warnings
```bash
# Bun installs peers by default (unlike npm)
# To disable: bunfig.toml → peer = false
```

### Global install location
```bash
# View global dir
bun pm bin -g

# Default: ~/.bun/bin
# Add to PATH if not already:
# export PATH="$HOME/.bun/bin:$PATH"
```

## 🔍 Debugging

### Verbose logging
```bash
bun install --verbose
bun test --verbose
```

### Check Bun version
```bash

bun upgrade             # Update to latest
bun upgrade --canary    # Bleeding edge
```

### Environment info
```bash
bun --print process.versions
bun --print process.platform
bun --print process.arch
```
