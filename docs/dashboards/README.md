# 📊 Dashboard Collection

This directory contains all the betting intelligence dashboards for the Betting-Brain v3 system.

## 🎯 Dashboard Overview

### **Position & Risk Tracker** ⭐
**File:** `dashboard-positions.html`  
**Purpose:** Real-time position tracking and risk analysis  
**Features:**
- Game-level exposure (home vs away)
- Customer position tracking
- Agent risk summary with scoring
- Auto-refresh every 10 seconds
- Export functionality

### **Enhanced Analytics Dashboard**
**File:** `dashboard-enhanced.html`  
**Purpose:** Advanced analytics with charts and alerts  
**Features:**
- 5 interactive charts
- CSV/JSON export
- Configurable alerts
- Customer/agent leaderboards
- Detailed wager modals

### **AI Intelligence Hub**
**File:** `dashboard-pro.html`  
**Purpose:** AI-powered insights and pattern recognition  
**Features:**
- 6 specialized tabs
- AI anomaly detection
- Smart search (⌘K)
- Keyboard shortcuts
- Risk scoring
- Customer segmentation

### **Basic Dashboard**
**File:** `dashboard.html`  
**Purpose:** Simple monitoring and debugging  
**Features:**
- Basic request/response tracking
- Simple statistics
- Response viewer

## 🚀 Quick Start

1. **Get Fresh Data:**
   - Use the browser extension (recommended)
   - Run console script from fantasy402.com
   - Use capture tool: `tools/capture-live-data.html`

2. **Open Dashboards:**
   - Position Tracker: `dashboards/dashboard-positions.html`
   - Enhanced: `dashboards/dashboard-enhanced.html`
   - AI Hub: `dashboards/dashboard-pro.html`
   - Basic: `dashboards/dashboard.html`
