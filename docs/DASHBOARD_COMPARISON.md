# 📊 Dashboard Comparison Guide

## Three Dashboards, Progressive Enhancement

### 1. **dashboard.html** - Basic Monitoring
**Use Case**: Simple API monitoring  
**Level**: Beginner  

**Features**:
- ✅ Basic request/response tracking
- ✅ Simple statistics
- ✅ Response viewer
- ✅ Minimal design

**Best For**: Quick checks, debugging, API testing

---

### 2. **dashboard-enhanced.html** - Advanced Analytics
**Use Case**: Full betting analytics with exports  
**Level**: Intermediate  

**Features**:
- ✅ All basic features +
- ✅ **5 interactive charts** (types, agents, timeline, segments, hourly)
- ✅ **CSV/JSON export** with full data
- ✅ **Configurable alerts** (high rollers, activity, volume)
- ✅ **Top customers & agents** leaderboards
- ✅ **Wager type filtering**
- ✅ **Detailed modals** with betting summaries
- ✅ Auto-refresh (10s)

**Best For**: Daily operations, trend analysis, data export

---

### 3. **dashboard-pro.html** - Intelligence Hub 🧠
**Use Case**: AI-powered betting intelligence  
**Level**: Professional  

**Features**:
- ✅ All enhanced features +
- ✅ **AI-Powered Insights**
  - Automatic anomaly detection
  - Pattern recognition
  - Risk scoring (0-100)
  - Customer concentration analysis
  - Velocity monitoring
- ✅ **6 Specialized Tabs**
  - 📊 Overview: Charts and quick stats
  - 👥 Customers: Deep customer analytics
  - 🏢 Agents: Performance metrics
  - 🔍 Patterns: Behavioral analysis
  - ⚠️ Risk: Risk events and scoring
  - ⚡ Live Feed: Real-time wagers
- ✅ **Smart Search** (⌘K)
  - Global search across customers, agents, wagers
  - Instant filtering
- ✅ **Keyboard Shortcuts**
  - `1-6`: Switch between tabs
  - `⌘K` / `Ctrl+K`: Global search
  - `ESC`: Close modals
- ✅ **Professional UX**
  - Smooth animations
  - Toast notifications
  - Loading states
  - Risk badges (Low/Medium/High/Critical)
  - Time-since indicators
  - Floating action button
- ✅ **Advanced Metrics**
  - Win rate estimation
  - Risk score calculation
  - Wager velocity (per minute)
  - Customer lifetime value
  - Agent performance scoring
  - Peak activity analysis
- ✅ **Saved Preferences**
  - Auto-refresh toggle
  - Theme selection (coming soon)
  - Saved filters

**Best For**: Professional analysis, risk management, strategic insights

## When to Use Each Dashboard

### Use **Basic Dashboard** (`dashboard.html`) when:
- 🔍 Quick debugging of API responses
- 🧪 Testing the interceptor
- 📱 Minimal resource usage needed
- 👨‍💻 Simple monitoring only

### Use **Enhanced Dashboard** (`dashboard-enhanced.html`) when:
- 📊 Need charts and visualizations
- 💾 Regular data exports required
- 🔔 Want alerts on specific events
- 📈 Analyzing trends over time
- 👥 Comparing customers/agents

### Use **Pro Dashboard** (`dashboard-pro.html`) when:
- 🧠 Need AI-powered insights
- ⚠️ Risk management is critical
- 🔍 Deep pattern analysis required
- 👔 Professional/executive reporting
- ⚡ Real-time monitoring essential
- 🎯 Strategic decision-making
- 🏆 Competitive intelligence
